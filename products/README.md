# Derived products

Products package selected Rebuild Labs capabilities for a particular
installation surface. They do not own rebuild research, domain contracts,
guides, evaluations, or editable skill instructions. Packaging makes a
capability installable; it is not evidence that the capability works.

The initial product is an experimental Codex plugin adapter. Product maturity
does not imply that the domain or its capabilities are stable, and packaging
does not authorize a rebuild in a target repository.
